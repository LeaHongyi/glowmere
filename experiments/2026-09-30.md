## 修改原链接还是 copy
| 情况 | 决策 | 理由 / 执行条件 |
| --- | --- | --- |
| 同一商品，仅优化主图、标题、tags、说明或商业条件 | 改原链接 | 保留链接连续性，按轮记录前后配置 |
| 仅换主展示色，且三个链接均已含多色选择 | 优先改原链接 | 现有三个链接已足够进行观察，不为了颜色再增加重复链接 |
| 访问少、无收藏、无订单，或观察周期未结束 | 不据此 copy | 先检查数据口径、曝光/流量来源、图片与购买信息；样本不足记无法判断 |
| 原链接有稳定销售，想探索明确不同的真实购买用途/人群 | 可考虑 copy | 先写独立假设，原链接冻结，准备对应真实定位的主图与文案，预设预算与结束条件 |
| 新组合、规格或商品确有独立购买理由 | 可新建或 copy 作模板 | 准确描述差异，单独核对选项、价格、库存和配送；不要把旧链接改成另一商品 |
| 完全相同的商品与定位，只想获得新链接初期流量 | 不推荐 copy | 暂时提升会干扰判断，新增链接不能视为继承原链接表现或稳定增量 |
| 有流量但无订单 | 先改原链接的购买障碍 | 核查尺寸、材质、配送、实际售价和展示信息；具体问题尚待核实 |
